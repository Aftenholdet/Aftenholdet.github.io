## Supplied MINDSTORMS visuals

The files under `mindstorms/` are WebP copies of the PNG exports supplied in `Images for Aftenholdet` on 14 September 2026. The four `cards/` images replace the generic program-logic card art when MINDSTORMS is selected. The four `blocks/` images provide block-code content for the matching Motor chapters. Their opaque `#121212` canvas is retained deliberately.

`Category Card Mindstorms - Wireless Communication.png` is not included because the current library has no matching Wireless Communication topic or source-backed guide content.
